À propos

Une issue que tu peux vraiment finir.

OpenToAll liste des issues GitHub encore libres, filtrées par langage, niveau et poids du clone — pour que tu clones et merges sans te battre contre un monolithe ou une issue déjà prise.

01 · Filtrer
Langage, niveau, poids du clone, fondation. Ce qui reste une fois les filtres appliqués est réellement libre et clonable.
02 · Choisir
Réactivité des mainteneurs, accueil des débutants, fichiers communautaires : les signaux qui disent si ta PR sera lue.
03 · Laisser une trace
Un profil public et un classement par pays pour montrer ce que tu as mergé — pas seulement un README que personne ne lit.

Le projet

OpenToAll est un registre ouvert : les issues viennent de dépôts réels et les signaux affichés sont vérifiables sur GitHub.
